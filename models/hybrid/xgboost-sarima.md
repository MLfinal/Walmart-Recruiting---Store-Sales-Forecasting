# XGBoost + SARIMA

ეს დირექტორია შეიცავს Walmart-ის ყოველკვირეული გაყიდვების `Store–Department` დონეზე პროგნოზირებისთვის შექმნილ XGBoost–SARIMA ჰიბრიდულ სამუშაო პროცესს: საბაზისო მოდელს, ექსპერიმენტსა და inference-ს.

## საბაზისო მოდელის გაწვრთნა

საბაზისო მოდელში გამოყენებული იყო ქრონოლოგიური, 39-კვირიანი ვალიდაციის პერიოდი. მონაცემები შემთხვევით არ დაყოფილა. Kaggle-ის შეწონილი საშუალო აბსოლუტური შეცდომის — WMAE-ის — შესაბამისად, სადღესასწაულო ჩანაწერებს მიენიჭა წონა `5`, ხოლო არასადღესასწაულო ჩანაწერებს — `1`.

XGBoost-ის კომპონენტი იყო გლობალური პანელური მოდელი, რომელიც ყველა `Store–Department` ჩანაწერზე გაიწვრთნა. გამოყენებული ძირითადი პარამეტრები:

- მიზნობრივი ფუნქცია: `reg:absoluteerror`
- ხეების რაოდენობა: `1200`
- სწავლის სიჩქარე: `0.03`
- ხის მაქსიმალური სიღრმე: `9`
- მინიმალური შვილობილი კვანძის წონა: `8`
- ჩანაწერების შერჩევის კოეფიციენტი: `0.85`
- სვეტების შერჩევის კოეფიციენტი: `0.80`
- L2 რეგულარიზაცია: `4.0`
- ხეების აგების მეთოდი: `hist`

ნიშან-თვისებები მოიცავდა მაღაზიას, განყოფილებას, სადღესასწაულო სტატუსს, მაღაზიის ტიპსა და ზომას, წელს, თვეს, ISO კვირის ნომერს და კვირის ციკლურ ნიშან-თვისებებს.

SARIMA კომპონენტი ცალ-ცალკე ერგებოდა თითოეულ `Store–Department` დროით მწკრივს, რომელსაც სულ მცირე 80 დაკვირვება ჰქონდა. გამოყენებული რიგები:

- არასეზონური რიგი: `(1, 0, 1)`
- სეზონური რიგი: `(0, 1, 1, 52)`

ჰიბრიდული პროგნოზი გამოითვლებოდა შეწონილი საშუალოს სახით:

```text
hybrid = xgb_weight * xgboost + (1 - xgb_weight) * sarima
```

ქრონოლოგიურ ვალიდაციაზე შემოწმდა XGBoost-ის წონები `0.50`-დან `0.90`-ის ჩათვლით.

## ანალიზი

XGBoost-ის საბაზისო მოდელი ნორმალურად გაიწვრთნა და ვალიდაციაზე მისაღები, დაახლოებით `2111.41` WMAE მიიღო. ეს გაშვება წარმატებულ ჰიბრიდულ მოდელს **არ** ადასტურებს.

SARIMA-მ სულ მცირე რამდენიმე `Store–Department` მწკრივისთვის რიცხობრივად უკიდურესად დიდი პროგნოზები შექმნა. კოდი მხოლოდ არაბოლო (`non-finite`) მნიშვნელობებს ანაცვლებდა, ამიტომ ძალიან დიდი, მაგრამ ფორმალურად ბოლო (`finite`) SARIMA პროგნოზები უცვლელად დარჩა. შედეგად, SARIMA-ს მხოლოდ 10%-იანმა წილმაც კი მთლიანად გადაფარა XGBoost-ის პროგნოზი და ჰიბრიდის WMAE კატასტროფულად გაზარდა.

`0.90` XGBoost წონის არჩევა მხოლოდ იმას აჩვენებს, რომ ვალიდაციამ SARIMA-ს შესაძლო წვლილიდან ყველაზე მცირე აირჩია. ეს არ ნიშნავს, რომ `0.90/0.10` რეალურად გამოსადეგი კომბინაციაა.

შესაბამისად:

- ამ გაშვებიდან მხოლოდ XGBoost-ის საბაზისო შედეგია სანდო.
- SARIMA-სა და ჰიბრიდის მიმდინარე ქულები პროგნოზირების რეალურ შედეგებად არ უნდა ჩაითვალოს.
- ეს საბაზისო pipeline `champion` მოდელად არ უნდა დარეგისტრირდეს.
- წონების მომავალ ძიებაში აუცილებლად უნდა დაემატოს XGBoost-ის `1.00` წონა; მიმდინარე გაშვებაში სწორედ დამოუკიდებელი XGBoost იქნებოდა არჩეული.

სრულ ექსპერიმენტამდე თითოეული SARIMA პროგნოზი უნდა შემოწმდეს:

- მოდელის convergence-ზე;
- მნიშვნელობების finiteness-ზე;
- ისტორიულ მასშტაბთან შესაბამისობაზე;
- რეალისტურ ქვედა და ზედა საზღვრებზე.

არასტაბილური SARIMA პროგნოზი უნდა ჩანაცვლდეს სეზონური naive ან XGBoost პროგნოზით. შერევამდე საჭიროა robust clipping თითოეული მწკრივის ისტორიული განაწილების მიხედვით. ექსპერიმენტმა ასევე უნდა დააფიქსიროს, რამდენ მწკრივზე იქნა გამოყენებული SARIMA, რამდენი მოდელი ჩავარდა და რამდენი პროგნოზი უარყოფილ იქნა არარეალისტური მნიშვნელობის გამო.
